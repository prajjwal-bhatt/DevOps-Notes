1. docker compose up -> Creates and starts the services defined in compose.yaml.

docker compose up
        ↓
Reads compose.yaml
        ↓
Builds images if needed
        ↓
Creates containers if needed
        ↓
Starts containers

2. docker compose build -> Only builds/rebuilds images for services having a build: configuration.
			   Does NOT create or start containers.

Ex:
	services:
	  backend:
	    build: ./backend
THEN,
	docker compose build

AND finally,
		 Dockerfile
    		     ↓
		docker build
    		     ↓
		Docker image


3. docker compose up --build -> Forces Compose to build/rebuild the images for services that have a build: configuration because if you have updated the docker file and the image of it, is created earlier so to use a updated image it will build the updated image and then create and start the container from that image.

- Builds/rebuilds the required images first.
- Then creates and starts the containers.

docker compose up --build
          ↓
     Read compose.yaml
          ↓
       build:
          ↓
      Dockerfile
          ↓
    Build/rebuild image
          ↓
    Create container
          ↓
     Start container


IN SHORT: 
		build       = Build images
		up          = Create + Start
		up --build  = Build images + Create + Start


---Docker Compose:
Tool used to define and manage multi-container Docker applications using a YAML configuration file.

Compose file is like this: compose.yaml

It defines:

	Services
	Images
	Ports
	Networks
	Volumes
	Environment variables

---YAML: 
It is a human readable configuration format.


---Important Commands

Command				Purpose
-----------------------------------------------------
docker compose up		Create/start services
docker compose up -d		Start in background
docker compose down		Stops and removes the compose managed containers and network
docker compose ps		List Containers belonging to Compose application
docker compose logs		View logs
docker compose logs -f		Follow logs
docker compose build		Build images
docker compose up -d --build	Build images and start containers
docker compose config		Docker dry runs the compose file to check errors
				Validates and renders the Compose file without creating or starting the containers
